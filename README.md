# 🚀 Полнофункциональная Канбан Доска

Современная веб-приложение для управления задачами с использованием методологии Канбан. Полностью реализованная система с расширенными возможностями для эффективного управления проектами.

## 🌟 Основные возможности

### 📋 Управление задачами
- **Три колонки статусов**: "К выполнению", "В процессе", "Готово"
- **Drag & Drop**: Интуитивное перетаскивание задач между колонками
- **CRUD операции**: Полное создание, редактирование, удаление задач
- **Приоритеты задач**: Высокий, Средний, Низкий с цветовой индикацией

### 🔍 Поиск и фильтрация
- **Умный поиск**: По названию, описанию и тэгам задач
- **Многоуровневые фильтры**:
  - По статусу (К выполнению/В процессе/Готово)
  - По приоритету (Высокий/Средний/Низкий)
  - По срокам (Просроченные/Сегодня/На этой неделе/Без срока)
  - По тэгам (динамический список всех используемых тэгов)

### 📅 Сроки выполнения
- **Поле даты выполнения** в формах создания/редактирования
- **Визуальные индикаторы**:
  - 🔴 **Просроченные задачи** (красная рамка и зачеркнутый текст)
  - 🟠 **Приближающиеся сроки** (оранжевая рамка, за 3 дня)
  - 🟢 **Своевременные задачи** (зеленая индикация)
- **Умное отображение**: "Сегодня", "Завтра", "Через N дней"

### 🏷️ Система тэгов
- **Ввод тэгов** через запятую (работа, срочное, проект)
- **Красивые цветные тэги** в карточках задач
- **Фильтрация по тэгам** с динамическим обновлением списка
- **Поиск по тэгам** включен в общий поиск

### 🌙 Темная тема
- **Полноценная темная тема** с плавными переходами
- **Переключатель темы** с сохранением предпочтений
- **CSS переменные** для поддержки всех элементов

### 📦 Архив и экспорт
- **Архив завершенных задач** с возможностью просмотра и восстановления
- **Экспорт данных** в JSON формате для резервного копирования
- **Безопасное удаление** задач навсегда

## 🎯 Как использовать

### Добавление задач
1. Нажмите **"Добавить задачу"** в заголовке или в любой колонке
2. Заполните форму:
   - **Название** задачи
   - **Описание** (опционально)
   - **Приоритет** (Высокий/Средний/Низкий)
   - **Срок выполнения** (опционально)
   - **Тэги** через запятую (опционально)
3. Нажмите **"Сохранить"**

### Управление задачами
- **Перетаскивание**: Захватите задачу и перетащите в нужную колонку
- **Редактирование**: Нажмите ✏️ иконку на задаче
- **Удаление**: Нажмите 🗑️ иконку на задаче

### Поиск и фильтрация
- Используйте **поле поиска** для быстрого нахождения задач
- Применяйте **фильтры** для точного отбора:
  - Фильтр по статусу задач
  - Фильтр по приоритету
  - Фильтр по срокам выполнения
  - Фильтр по тэгам

### Темная тема
- Нажмите **🌙** кнопку для переключения между светлой и темной темой
- Настройки сохраняются автоматически

### Архив задач
- Нажмите **📦** кнопку "Архив задач"
- Просмотрите завершенные задачи
- Восстановите задачу или удалите навсегда

### Экспорт данных
- Нажмите **💾** кнопку "Экспорт данных"
- Скачается JSON файл со всеми задачами
