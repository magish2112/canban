# Канбан Доска

Современная веб-приложение для управления задачами с использованием методологии Канбан. Приложение позволяет визуально организовывать и отслеживать прогресс выполнения задач.

## 🚀 Возможности

- **Три колонки статусов**: "К выполнению", "В процессе", "Готово"
- **Drag & Drop**: Перетаскивание задач между колонками
- **Приоритеты задач**: Высокий, Средний, Низкий с цветовой индикацией
- **CRUD операции**: Создание, редактирование, удаление задач
- **Локальное хранение**: Данные сохраняются в localStorage браузера
- **Адаптивный дизайн**: Работает на всех устройствах
- **Современный UI**: Красивый интерфейс с анимациями

## 📁 Структура проекта

```
├── index.html          # Основной HTML файл
├── styles.css          # Стили и CSS анимации

└── README.md          # Документация
```

## 🎯 Как использовать

### Запуск приложения
1. Откройте файл `index.html` в любом современном браузере
2. Приложение готово к использованию!

### Добавление задач
- Нажмите кнопку "Добавить задачу" в заголовке
- Или нажмите "Добавить задачу" в любой колонке
- Заполните форму и нажмите "Сохранить"

### Управление задачами
- **Перетаскивание**: Захватите задачу и перетащите в другую колонку
- **Редактирование**: Нажмите иконку карандаша на задаче
- **Удаление**: Нажмите иконку корзины на задаче

### Приоритеты
- **Высокий** (красный): Критически важные задачи
- **Средний** (оранжевый): Обычные задачи
- **Низкий** (зеленый): Несрочные задачи

## 🎨 Особенности дизайна

- **Градиентный фон**: Красивый градиентный фон
- **Стеклянный эффект**: Полупрозрачные элементы с размытием
- **Анимации**: Плавные переходы и hover-эффекты
- **Иконки**: Font Awesome иконки для лучшего UX
- **Адаптивность**: Оптимизировано для мобильных устройств

## 💾 Хранение данных

Все данные сохраняются локально в браузере (localStorage). При первом запуске приложение создает несколько примеров задач для демонстрации функциональности.

## 🔧 Технические детали

- **HTML5**: Семантическая разметка
- **CSS3**: Flexbox, Grid, анимации, градиенты

- **Drag & Drop API**: Нативная поддержка перетаскивания

При первом запуске приложение автоматически создает несколько примеров задач:

- **Создать дизайн интерфейса** (Средний приоритет, В процессе)
- **Настроить систему контроля версий** (Низкий приоритет, Готово)
